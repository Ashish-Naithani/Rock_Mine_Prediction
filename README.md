# Rock vs Mine Prediction using Machine Learning

## 📌 Project Overview
This project builds a Machine Learning model that predicts whether an object detected by sonar is a **Rock** or a **Mine**. The model is trained on the **Sonar dataset**, which contains sonar signals bounced off different surfaces under the sea.

The goal of this project is to demonstrate how machine learning algorithms can classify underwater objects based on sonar signal patterns.

---

## 📊 Dataset Information
The dataset used in this project is the **Sonar Dataset** from the UCI Machine Learning Repository.

- Total Instances: 208
- Total Features: 60
- Feature Type: Numerical
- Target Classes:
  - **R** → Rock
  - **M** → Mine

Each feature represents the **energy of sonar signals at different frequency bands**.

## 🤖 Model Used

The model used in this project:

- **Logistic Regression**

Logistic Regression is suitable for binary classification problems like Rock vs Mine detection.

## 📈 Model Performance

- Accuracy on Training Data: ~83%
- Accuracy on Test Data: ~81%
